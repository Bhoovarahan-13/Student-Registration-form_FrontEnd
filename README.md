# Responsive Student Registration Form

A responsive Student Registration Form built using HTML, CSS, and JavaScript. The application collects student details and dynamically displays them in a table without refreshing the page.

## Features

- Responsive design for Desktop, Tablet, and Mobile
- Form validation using HTML and JavaScript
- Dynamic table row insertion
- Prevents page refresh using `event.preventDefault()`
- Uses `addEventListener()` (No inline JavaScript)
- Automatically resets the form after submission
- Clean and modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## Form Fields

- First Name
- Last Name
- Email
- Address
- Pincode
- Gender
- State
- Country
